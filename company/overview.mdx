The **Overview** page is the first page of your company's dashboard. Everyone can open it. Admins also see your company's API key and role settings.

<Note>
  **Screenshot needed:** The Overview page as an admin, showing the API Key and Roles sections.
</Note>

## API key

Your API key lets your Roblox game connect to FleetPoint. You'll need it when you [connect your game](/connect).

The key is hidden by default. Click the eye icon to show it, then select it to copy it.

<Warning>
  Keep your API key secret. Anyone with it can send data to FleetPoint as your company. If you think it's been leaked, [contact support](https://fleetpointapp.com/support) to have a new one generated.
</Warning>

## Roles

Choose the minimum Roblox group rank for each role:

- **Minimum Driver Rank**: the rank a member needs before the dashboard opens at all.
- **Minimum Mechanic Rank**: takes buses in and out of service.
- **Minimum Supervisor Rank**: assigns drivers, and reads the live map, activity logs, and replays.
- **Minimum Admin Rank**: everything, including the fleet, maps, and subscriptions.

Click **Save** to apply. The rules are:

- Each rank must be a whole number from 1 to 250.
- Each role has to start at or above the one below it: driver, then mechanic, then supervisor, then admin.
- You can't set the Minimum Admin Rank above your own rank, so you can't lock yourself out.

<Tip>
  Find your group's rank numbers in your group's settings on Roblox, under **Roles**.
</Tip>

See [Roles & Permissions](/roles) for what each role can do.
